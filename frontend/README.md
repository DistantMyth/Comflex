# Comflex Frontend

Rebuilt frontend for the Comflex campus collaboration platform.

## Features & Stack
- **React 19** + **Vite**
- **Tailwind CSS 4**
- **Framer Motion 12** + **GSAP 3** (with ScrollTrigger)
- **Matte + Glassy Design System** with fluid optical liquid glass shaders
- **Socket.IO** client for real-time channels & instant messaging
- **Responsive Layout** with light & dark mode support

## Getting Started
```bash
npm install
npm run dev
```

Build for production:
```bash
npm run build
```
